# 🍱 오늘식단

> AI 기반 음식 칼로리 & 영양소 분석 웹 서비스

## 📌 프로젝트 소개

음식 이름을 입력하면 Google Gemini AI가
칼로리, 영양소, 식단 조언을 자동으로 분석해주는 웹 서비스입니다.

## ✨ 주요 기능

- 🔍 음식 이름 입력 → AI 자동 분석
- 📊 칼로리 & 영양소 정보 제공 (탄수화물/단백질/지방)
- 💬 맞춤형 식단 조언 출력
- 📱 반응형 UI 디자인

## 🛠️ 기술 스택

| 분류 | 기술 |
|------|------|
| Frontend | HTML, CSS, JavaScript |
| AI API | Google Gemini API |
| 개발 도구 | VS Code, Live Server |
| 버전 관리 | Git, GitHub |
